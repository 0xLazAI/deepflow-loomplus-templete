# PRD

## 1. 当前轮目标
验证活动报名系统 MVP 是否可以完成用户提交报名信息并让后台查看列表。

## 2. 用户与场景
### 主要用户
- 报名用户
- 运营人员

### 核心场景
- 用户打开报名页，填写信息并提交
- 运营查看后台列表确认报名数据是否正常进入系统

## 3. 功能范围
### 必须有
- 报名表单页
- 提交成功反馈
- 后台报名列表页
- 报名数据入库与查询

### 可延后
- 登录
- 导出
- 权限系统
- 审核流程

## 4. 页面 / 模块
- 前台报名页
- 提交成功页或提示
- 后台报名列表页

## 5. 数据与字段
- 姓名
- 手机号
- 公司 / 组织（可选）
- 备注（可选）

## 6. 业务规则
- 姓名、手机号为必填
- 提交成功后要有明确反馈
- 后台列表需能看到已提交数据

## 7. 默认假设
- 第一轮后台不需要登录
- 第一轮不区分角色
- 钱包地址本轮不做必填字段

## 8. 当前验收标准
- 用户可以完成报名提交
- 后台可以看到用户提交的数据
- 整条流程可供需求方 review
